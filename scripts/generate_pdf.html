1. Project Overview & System Purpose

Spendorio is a production-grade, full-stack personal finance and daily routine management platform designed with an Offline-First Progressive Web App (PWA) architecture. Unlike traditional web applications that fail when internet connectivity drops, Spendorio provides native mobile app performance, sub-second launch times (<0.5s), and complete offline autonomy, backed by an enterprise Java Spring Boot RESTful API backend.

4. Detailed Technology Stack & Tooling

A. Backend Architecture (Spring Boot & Enterprise Java)

  • Spring Boot 3.3.4 Provides the core enterprise framework, dependency injection, and autoconfiguration.
  • Spring Web MVC Dispatches RESTful endpoints using @RestController, @GetMapping, @PostMapping, and @PutMapping.
  • Embedded Apache Tomcat High-throughput web server handling parallel HTTP connections on port 3000 without requiring standalone server installations.
  • Jackson Databind High-performance JSON serializer and deserializer mapping HTTP payloads into strongly typed Java POJOs (User.java).
  • Java Concurrency (ReentrantLock) Thread synchronization ensuring that simultaneous requests from multiple users never collide or produce dirty writes.
  • Atomic File I/O Engine Writes updates to randomized temporary files (.tmp) before executing an atomic OS rename, guaranteeing zero database corruption during sudden power losses.
  • Golden Safeguard Protection Algorithmic security layer in DataService that rejects any sync payload containing fewer than 50 records for the owner, preventing data loss.

B. Frontend & Progressive Web App (PWA) Technologies

  • Service Worker (sw.js) A background worker script that intercepts all network requests. Implements a Cache-First strategy for static assets (HTML, CSS, JS, icons) and a Network-First strategy for API calls.
  • Web App Manifest (manifest.json) JSON specification declaring application branding, theme colors (#0f172a), high-resolution icons (192px, 512px), and "display": "standalone" mode to eliminate browser address bars.
  • WebAPK Technology Android's native packaging mechanism that compiles the installed PWA directly into the Android OS app drawer alongside native Play Store apps.
  • Offline-First Client Sync Engine Asynchronous background reconciliation engine in storage.js that persists mutations instantly to localStorage and syncs with the Spring Boot server whenever online.

C. Cloud Networking & Security

  • Cloudflare Tunnel (cloudflared) Creates an outbound-only encrypted tunnel between the laptop's port 3000 and Cloudflare's nearest edge server (Chennai - maa03).
  • HTTP/2 TCP Protocol Low-latency, multiplexed transport eliminating Indian ISP UDP/QUIC socket drops.
  • End-to-End SSL/TLS Encryption Delivers bank-grade HTTPS encryption, fulfilling strict mobile OS requirements for PWA installation.
  • Zero Port-Forwarding Security The host laptop's public IP remains completely hidden; external access to Windows OS, drives, or camera is physically impossible.
