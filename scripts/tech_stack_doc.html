2. Frontend Coding Technologies Explained

1. Vanilla JavaScript (ES6+) — Core Frontend Logic

Written in modern JavaScript (ES6 Modules, Promises, Async/Await, Arrow Functions, Fetch API) without heavy libraries like React or Angular. This ensures the app loads in less than 50 milliseconds and consumes under 15MB of device RAM.

  • app.js: Application controller coordinating UI screens, navigation, and theme toggling.
  • storage.js: Central client-side data store with automatic bi-directional server synchronization.
  • expenses.js & tasks.js: Expense filtering, category math, and daily routine streak algorithms.
  • charts.js: Interactive visual monthly budget analytics and spending distribution charts.
2. Progressive Web App (PWA) & Service Worker (sw.js)

The core technology that allows Spendorio to install and work like a native mobile app from the Google Play Store:

  • sw.js (Service Worker): Operates as a background network proxy. Implements a Cache-First strategy for static assets (HTML, CSS, JS, icons) so the app opens instantly even in airplane mode.
  • manifest.json: Web App Manifest configuring the app title, dark theme splash color (#0f172a), high-resolution icons (192px & 512px), and "display": "standalone" mode to remove the browser address bar.
  • Android WebAPK Engine: Android OS compiles the installed manifest directly into a native WebAPK in the App Drawer.
3. HTML5 & CSS3 — Glassmorphism Design System

Semantic HTML5 structure paired with custom CSS3 variables, flexbox, and grid layouts. Employs modern Glassmorphism UI (frosted glass blur using backdrop-filter: blur(12px)) with responsive design for mobile, tablet, and desktop.

3. Backend Coding Technologies Explained

1. Java (JDK 25 LTS) — Enterprise Language

The backend is built in Java, the industry-standard language used by banks, financial institutions, and Fortune 500 tech companies. Java provides strict type safety, multithreading, and compile-time error detection that prevents crashes.

2. Spring Boot 3.3.4 & Spring MVC — Backend Framework

Provides production-grade REST API architecture with zero boilerplate:

  • SpendorioApplication.java: @SpringBootApplication entry point bootstrapping the application.
  • AuthController.java: @RestController exposing /api/auth/login, /api/auth/register, and /api/auth/check-availability.
  • SyncController.java: @RestController managing live device data synchronization (GET /api/sync and POST /api/sync).
  • HealthController.java: @RestController for system monitoring and uptime verification (GET /api/health).
  • WebConfig.java: Configures global Cross-Origin Resource Sharing (@CrossOrigin) and routes frontend static assets from public/.
3. Embedded Apache Tomcat (Port 3000)

Spring Boot packages an embedded Apache Tomcat web server directly inside the executable JAR. There is no need to install external web servers; it runs autonomously on port 3000.

4. Jackson Databind & Java Models (POJOs)

Jackson automatically maps incoming JSON HTTP requests into strongly typed Java objects (User.java) and serializes backend responses into JSON with zero translation errors.

5. DataService & Concurrency Engine (Thread Safety)

A specialized service layer engineered to protect data integrity under concurrent user access:

  • ReentrantLock: Prevents race conditions when multiple users or devices push data simultaneously.
  • Atomic File I/O: Writes updates to temporary files before executing an atomic OS rename, preventing file corruption if the laptop loses power.
  • Golden Safeguard: Rejects any overwrite of the primary owner's database containing fewer than 50 records, ensuring Mukilan's 91 records (₹1,16,326) are never wiped.

4. Cloud & Edge Networking

Cloudflare Edge Tunnel (cloudflared)
  • Outbound Encrypted Tunnel: Connects the laptop's port 3000 to Cloudflare's nearest data center (Chennai - maa03).
  • HTTP/2 TCP Protocol: High-speed multiplexed transport with zero packet drop across Indian mobile networks.
  • Bank-Grade HTTPS / SSL: Green padlock encryption satisfying Android/iOS security requirements for PWA installation.
  • Total Laptop Isolation: Windows operating system, C: drive, and personal files remain completely hidden from the internet.
